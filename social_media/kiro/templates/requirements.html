User story: As a note-taking user, I want to search titles so I can find a note quickly.

Acceptance criteria

  1. WHEN a user enters a query, THE app SHALL match note titles without case sensitivity.
  2. WHEN the query is empty, THE app SHALL display all notes.
  3. WHEN no note matches, THE app SHALL display an empty-results message.
  4. THE search field SHALL support keyboard navigation.
